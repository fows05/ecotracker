# Архитектура EcoTracker (учебный прототип)

| Модуль | Назначение | Требование |
|---|---|---|
| storage.py | Приём, проверка и хранение измерений (SQLite) | FR-1, FR-2 |
| analytics.py | Расчёт AQI, категории качества воздуха, среднее | FR-3 |
| alerts.py | Проверка ПДК, формирование оповещений | FR-4 |
| reports.py | Экспорт измерений в CSV | FR-6 |
